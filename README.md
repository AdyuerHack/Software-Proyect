# Software-Proyect

Este repositorio contiene pequeños ejercicios para practicar Python.

## Juego del ahorcado

Ejecuta el archivo `main.py` para jugar desde la consola:

```bash
python main.py
```

Opcionalmente puedes proporcionar un fichero con palabras personalizadas y el número de intentos:

```bash
python main.py --word-file mis_palabras.txt --attempts 10
```

El fichero de palabras debe contener una palabra por línea, usando únicamente caracteres alfabéticos.
